Log in with your own TeamCity (ci2) access token. There is no shared account: TeamCity records the runs you start or cancel here as yours. Until you log out, but no longer than about an hour after your last request, the server keeps your token in memory, which can reach the disk through the host's swap. It uses the token only to read from TeamCity, to check open PRs for everyone.

Create a token
What the checker does with your token
  • Your browser keeps it in an encrypted session cookie.
  • After login, the ⚙ menu has options that work while this page is closed. While one is on, the server stores the token encrypted, until you turn them all off. Copies stay in server backups until the backups are replaced. With any option other than PR commands on, the server also keeps using the token to read from TeamCity, to check open PRs for everyone.
  • Your login ends when you log out (in every browser at once) or after 400 days without use.
No ci2 account or token yet?
  1. Register an account on ci2, the TeamCity of Apache Ignite.
  2. Create an access token there: Profile → Access Tokens (“Create a token” above opens it).
  3. The token acts with your account's rights. Reading verdicts needs only view access; Run and Rerun need the right to run builds, “Run at top” and “Rerun at top” also to reorder the build queue (without it, TeamCity queues them at the end), and “Cancel my runs” to stop builds and remove them from the queue.

What the badges mean
  • ✓clean — a run of the PR's current code blamed nothing on it
  • !started failing — no blockers yet, but tests started failing on its code; a rerun shows whether they are blockers
  • ?not proven clean — no blockers found, but the run can't prove the PR clean
  • …checking — only for the PR open on the page: checking that the run tested its latest commit
  • 2blockers — tests the PR most likely broke
  • my runmy run — you started its latest RunAll
  • no badge — no verdict yet
