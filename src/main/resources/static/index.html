An open-source continuous-integration tool for Apache Ignite contributors — source on GitHub. It reads the project's TeamCity CI (ci2) to tell real regressions from pre-existing flaky failures.

Create a token
Log in with your own TeamCity (ci2) access token. There is no shared server token: the runs you start or cancel here go under your account.
The token is kept encrypted in your session cookie. For about an hour after your last request the server also holds it in memory and uses it only to read from TeamCity, to pre-analyse open PRs for everyone.
Turn on an option in ⚙ and the server stores the token encrypted until you turn the options off. With any option other than PR commands on, it also keeps doing those reads.
Your login lasts until you log out.
No ci2 account or token yet?
  1. Register an account on ci2, the TeamCity of Apache Ignite.
  2. Create an access token there: Profile → Access Tokens (“Create a token” above opens it).
  3. The token acts with your account's rights. Reading verdicts needs only view access; Run and Rerun need the right to run builds, “Run at top” and “Rerun at top” also to reorder the build queue, and “Cancel my runs” to stop builds and remove them from the queue.
